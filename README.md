# MobileApp project

a studen tproject fo a mobile app, built with React Native and ExpoGo.

## Features

- **Authentication**
    - User registration and login using Firebase Authentication
    - Authenticated user data is stored in an AuthProvider and shared across the app
      
- **Homepage**
    - View all upcoming events in map view and list view
    - Filter events by:
      - Date
      - Activity type (walk or run)
    - Displays the user's location on the map
 
- **Create event**
    - Create and publish new walking or running event
 
- **Profilepage**
    - View the events you have:
      - created
      - joined
    - View and edit personal information such as Name, birthdate, city...
 
- **Statistics**
    - View statistics for your walks and runs
    - Monthly and yearly overviews of activity data
 
- **Tracker**
    - Track your walks/runs.
